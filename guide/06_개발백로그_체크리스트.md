# 06. SKale 개발 백로그 및 체크리스트

## 1. 개발 목표

기한 내 목표는 “완전한 금융 서비스”가 아니라 “대부분의 기능이 실제로 굴러가는 AI Agent 프로토타입”이다.

최종 시연 기준:

```text
소비 내역 입력 → AI 분류 → 차트 반영 → 자산 입력 → 순자산 비교 → 포트폴리오 추천 → 종목 분석
```

## 4. API 실패 fallback 정책

| 기능 | 실패 시 처리 |
|---|---|
| 소비 분석 | 예시 분석 결과 표시 |
| 자산 분석 | 예시 자산 분석 결과 표시 |
| 포트폴리오 추천 | 기본 중립형 배분 표시 |
| 종목 분석 | 데이터 부족 결과 표시 |
| 이미지 분석 | 직접 입력 방식 안내 |
