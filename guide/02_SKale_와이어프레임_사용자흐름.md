# 02. SKale 와이어프레임 및 사용자 흐름

## 1. 전체 화면 구조

```text
SKale
├── Dashboard
├── 소비 분석
├── 자산 분석
├── 포트폴리오 추천
└── 종목 분석
```

초안 대비 `종목 분석` 화면을 추가한다. 사용자의 투자 전략을 단순 자산 배분이 아니라 실제 관심 종목 검토까지 연결하기 위함이다.

---

## 2. 공통 레이아웃

```text
┌──────────────────────────────────────────────────────────────┐
│ SKale                     Dashboard 소비 자산 포트폴리오 종목 │
├──────────────────────────────────────────────────────────────┤
│                                                              │
│  페이지 제목                                                  │
│  페이지 설명                                                  │
│                                                              │
│  [AI 안내 카드]                                               │
│  주요 입력 영역                                                │
│  주요 결과 영역                                                │
│                                                              │
└──────────────────────────────────────────────────────────────┘
```

### 공통 UX 원칙

- 입력 전에는 예시 데이터 버튼을 먼저 보여준다.
- 분석 중에는 로딩 문구를 보여준다.
- 분석 실패 시 직접 입력 또는 예시 결과로 이어지게 한다.
- AI 결과에는 항상 `확인 필요`와 `신뢰도` 개념을 둔다.
- 금융 판단 화면에는 참고용 고지 문구를 표시한다.

## 8. 1분 시연 흐름

```text
1. Dashboard에서 SKale이 소비·자산·투자를 연결하는 Agent임을 보여준다.
2. 소비 분석 화면에서 예시 데이터를 불러오고 AI 분석 결과를 보여준다.
3. 자산 분석 화면에서 순자산 계산과 이전 대비 변화를 보여준다.
4. 포트폴리오 화면에서 투자 성향 기반 자산 배분을 보여준다.
5. 종목 분석 화면에서 stock_strategy 기준의 점수화 결과를 보여준다.
```

## 9. 3분 시연 흐름

```text
1. 문제 제기
   - 금융 데이터는 여러 앱에 흩어져 있고, 사용자는 전체 돈 흐름을 보기 어렵다.

2. 소비 분석
   - 결제 내역 입력 또는 캡처 업로드
   - AI가 고정비, 생활비, 여행, 투자 등으로 자동 분류

3. 자산 분석
   - 현재 자산 현황 입력
   - 총자산, 부채, 순자산 계산
   - 이전 기록과 비교

4. 포트폴리오 추천
   - 투자 성향과 투자 기간 입력
   - 자산 배분 방향 제안

5. 종목 분석
   - 관심 종목 정보를 입력
   - 간소화된 투자 전략 기준으로 산업, 경쟁우위, 재무, 가격, 리스크 점수화

6. 마무리
   - SKale은 단순 가계부가 아니라 사용자의 돈 흐름을 읽고 다음 행동을 제안하는 AI Agent이다.
```
