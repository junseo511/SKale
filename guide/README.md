## 핵심 방향

- 서비스명: **SKale**
- 서비스 성격: 소비·자산·투자 전략을 연결하는 개인 자산관리 AI Agent
- 구현 우선순위: 직접 입력 분석 → 시각화 → 자산 비교 → 포트폴리오 추천 → 캡처 분석 → 종목 분석
- AI 안정성 원칙: JSON 스키마, confidence, needReview, fallback, 민감정보 안내, 투자 고지

## 가장 중요한 수정 포인트

초안은 전체 흐름은 좋았지만, 실제 사용자에게 도움 되는 Agent가 되려면 다음이 보강되어야 합니다.

1. AI가 모르는 정보를 지어내지 않도록 `missingData`, `assumptions`, `needReview` 필드를 둔다.
2. 소비/자산 분석 결과를 화면에 바로 쓰기 위해 JSON 스키마를 고정한다.
3. 투자/종목 분석은 매수 지시가 아니라 `검토 후보군 분석`으로 표현한다.
4. 주식 종목 분석은 최신 재무 데이터가 없으면 “분석 불가 항목”을 명확히 표시한다.
5. 모든 핵심 기능은 API 실패 시 mock fallback으로 시연 가능해야 한다.
