# SKale 기능명세서 및 개발 기획 문서

> **서비스명:** SKale  
> **슬로건:** AI로 소비를 읽고, 자산을 키우다.  
> **문서 목적:** 신입구성원 연수 과제 제출 및 실제 React 기반 AI Agent 개발을 위한 기능명세서, 화면 설계, AI 처리 흐름, 데이터 구조, 개발 우선순위를 정의한다.

---

## 1. 프로젝트 개요

### 1.1 서비스 소개

**SKale**은 사용자의 소비 내역과 자산 현황을 AI가 분석하여, 현재 돈의 흐름을 시각화하고 다음 자산 관리 행동을 제안하는 개인 자산관리 AI Agent이다.

사용자는 카드 결제 내역, 은행 앱 자산 현황, 투자 계좌 현황 등을 직접 입력하거나 캡처 이미지로 첨부할 수 있다. SKale은 이를 분석하여 소비 항목을 자동 분류하고, 고정비·생활비·여행·투자 등 카테고리별로 정리한다. 또한 이전 자산 상태와 현재 상태를 비교하여 순자산 변화, 소비 패턴 변화, 투자 여력 등을 요약한다.

최종적으로 사용자의 투자 성향과 사용자가 작성한 투자 전략을 반영하여 자산 배분 방향과 포트폴리오 후보군을 제안한다.

---

### 1.2 제작 배경

개인의 금융 정보는 카드 앱, 은행 앱, 증권 앱, 간편결제 앱 등에 흩어져 있다. 사용자는 여러 앱을 직접 확인해야 전체 자산 상태를 파악할 수 있고, 소비 내역을 직접 분류하거나 투자 여력을 계산해야 한다.

기존 가계부 서비스는 주로 기록과 통계에 초점이 있다. 하지만 사용자가 실제로 필요한 것은 단순한 기록이 아니라 다음과 같은 질문에 대한 답이다.

- 이번 달에 어디에 돈을 많이 썼는가?
- 고정비와 생활비 비중은 적절한가?
- 지난달보다 자산 상태가 좋아졌는가?
- 현재 투자 여력은 어느 정도인가?
- 내 투자 성향과 전략에 맞는 자산 배분은 무엇인가?
- 앞으로 어떤 행동을 줄이거나 늘려야 하는가?

SKale은 이러한 질문에 대해 AI가 소비와 자산 데이터를 읽고, 요약하고, 다음 행동을 제안하는 Agent를 목표로 한다.

---

### 1.3 핵심 가치

| 가치 | 설명 |
|---|---|
| 자동화 | 사용자가 직접 분류하지 않아도 AI가 소비 내역과 자산 현황을 구조화한다. |
| 개인화 | 사용자의 소비 패턴, 투자 성향, 투자 전략을 반영한다. |
| 시각화 | 복잡한 자산 흐름을 React 기반 대시보드로 직관적으로 보여준다. |
| 행동 제안 | 단순 통계가 아니라 다음 자산 관리 행동을 제안한다. |
| 시연 가능성 | 짧은 시간 안에 AI Agent의 활용 가능성을 보여줄 수 있다. |

## 2. 서비스명 정의

### 2.1 최종 서비스명

## SKale

### 2.2 이름 의미

**SKale = SK + Scale**

- Scale: 자산을 키우다.
- Scale: 비중을 조정하다.
- Scale: 현재 상태를 측정하다.
- SK: 과제 맥락과 연결되는 브랜드적 요소.

### 2.3 서비스 한 줄 소개

> SKale은 소비 내역과 자산 현황을 AI가 분석하여 사용자의 돈 흐름을 시각화하고, 자산 배분과 투자 방향을 제안하는 개인 자산관리 AI Agent입니다.

### 2.4 대체 이름 후보

| 이름 | 의미 | 평가 |
|---|---|---|
| SKale | SK + Scale | 가장 자연스럽고 자산 성장, 비중 조정, 시각화 의미가 모두 살아 있음 |
| SKan | SK + Scan | 캡처 분석 기능을 강조하기 좋음 |
| SKore | SK + Score | 자산 건강 점수 기능과 잘 맞음 |
| SKoop | SK + Scoop | 흩어진 금융 정보를 모은다는 의미이나 다소 가벼움 |
| SKetch | SK + Sketch | 자산 흐름을 그린다는 의미이나 금융 서비스 느낌은 약함 |

## 3. 목표 사용자

### 3.1 주요 사용자

- 소비 내역을 체계적으로 관리하고 싶은 사회초년생
- 월급, 생활비, 저축, 투자 비중을 정리하고 싶은 직장인
- 토스, 은행 앱, 증권 앱에 흩어진 자산 현황을 한 번에 보고 싶은 사용자
- 투자 전략은 있지만 실제 자산 배분으로 연결하기 어려운 사용자
- 자신의 소비 습관을 개선하고 장기 자산 형성을 하고 싶은 사용자

### 3.2 사용자 페르소나

#### Persona A. 사회초년생 직장인

- 월급을 받기 시작했지만 소비·저축·투자 비중을 어떻게 나눠야 할지 고민한다.
- 매달 카드값과 고정비가 얼마나 나가는지 감으로만 알고 있다.
- 토스와 은행 앱에서 자산을 확인하지만 전체적인 흐름을 정리하지 못한다.
- AI가 현재 상태를 요약하고 다음 행동을 알려주길 원한다.

#### Persona B. 투자 관심이 있는 사용자

- 자신만의 투자 전략을 가지고 있다.
- 구조적으로 성장하는 산업, 재무제표, 장기 보유 관점에 관심이 있다.
- 다만 월별 투자 가능 금액과 현금 비중을 어떻게 가져가야 할지 고민한다.
- AI가 투자 성향과 전략을 반영해 포트폴리오 방향을 제안해주길 원한다.

## 4. 문제 정의

### 4.1 사용자의 문제

1. 금융 데이터가 여러 앱에 흩어져 있다.
2. 소비 내역을 직접 분류하기 번거롭다.
3. 고정비와 변동비의 비중을 직관적으로 파악하기 어렵다.
4. 현재 순자산과 이전 대비 변화를 계산하기 어렵다.
5. 투자 전략은 있어도 실제 포트폴리오 비중으로 연결하기 어렵다.
6. 단순 통계보다 개인 상황에 맞는 행동 제안이 필요하다.

### 4.2 해결 방향

SKale은 다음 방식으로 문제를 해결한다.

1. 소비 내역 입력 또는 캡처 업로드
2. AI 기반 내역 추출 및 카테고리 자동 분류
3. 자산 현황 입력 또는 캡처 업로드
4. 총자산, 부채, 순자산 자동 계산
5. 이전 기록과 현재 기록 비교
6. 사용자 성향 기반 자산 배분 추천
7. 투자 전략 기반 포트폴리오 후보군 제안
8. React 대시보드 기반 시각화 제공

## 6. 핵심 사용자 시나리오

### 6.1 소비 분석 시나리오

1. 사용자가 이번 달 소비 내역을 붙여넣는다.
2. 사용자가 `AI 분석하기` 버튼을 누른다.
3. SKale이 소비 내역에서 날짜, 사용처, 금액을 추출한다.
4. SKale이 각 내역을 카테고리로 자동 분류한다.
5. 사용자는 지출 카드와 카테고리 차트를 확인한다.
6. SKale이 이번 달 소비 패턴에 대한 코멘트를 제공한다.

#### 예시 입력

```text
6/25 스타벅스 6,300원
6/25 월세 500,000원
6/25 쿠팡 42,000원
6/25 지하철 1,550원
6/25 대한항공 248,000원
6/25 미래에셋증권 300,000원
```

#### 예시 출력

```text
이번 달 지출 중 고정비와 여행 지출의 비중이 높습니다.
월세는 반복 지출로 고정비에 해당하며, 대한항공 결제는 여행 카테고리로 분류했습니다.
미래에셋증권 입금은 소비가 아니라 투자 항목으로 분류했습니다.
```

---

### 6.2 자산 분석 시나리오

1. 사용자가 토스 또는 은행 앱의 자산 현황을 입력하거나 캡처로 첨부한다.
2. SKale이 자산 항목과 금액을 추출한다.
3. SKale이 현금성 자산, 투자 자산, 저축성 자산, 부채/미결제로 구분한다.
4. 총자산, 부채, 순자산을 계산한다.
5. 이전 자산 상태와 현재 상태를 비교한다.
6. 변화 요약과 AI 코멘트를 제공한다.

#### 예시 입력

```text
토스뱅크 1,200,000원
카카오뱅크 800,000원
주식계좌 3,500,000원
청약 1,000,000원
신용카드 미결제 420,000원
```

#### 예시 출력

```text
총자산은 6,500,000원입니다.
미결제 금액 420,000원을 제외한 순자산은 6,080,000원입니다.
지난 기록 대비 순자산은 330,000원 증가했습니다.
현금성 자산과 투자 자산이 모두 증가했고, 미결제 금액은 감소했습니다.
```

---

### 6.3 자산 배분 및 포트폴리오 추천 시나리오

1. 사용자가 투자 성향을 선택한다.
2. 투자 기간, 관심 산업, 월 투자 가능 금액을 입력한다.
3. 사용자가 자신의 투자 전략을 입력한다.
4. SKale이 투자 성향과 전략을 해석한다.
5. 현금, ETF, 성장 산업 후보, 개별 종목 후보, 대기자금 비중을 제안한다.
6. 추천 이유와 리스크 코멘트를 제공한다.

#### 예시 입력

```text
투자 성향: 중립형
투자 기간: 3년 이상
관심 산업: AI, 반도체, 전력 인프라
월 투자 가능 금액: 300,000원

투자 전략:
먼저 구조적으로 커지는 산업을 찾고, 그 산업 안에서 경제적 과실을 많이 가져갈 기업을 고른다. 이후 재무제표를 통해 매출 성장성, 영업이익률, 현금흐름, 부채비율을 확인하고, 시가총액이 아직 과도하게 반영되지 않은 구간에서 장기 보유한다.
```

#### 예시 출력

```text
중립형 성향과 3년 이상의 투자 기간을 고려하면, 코어 자산을 중심으로 안정성을 확보하고 일부 비중을 성장 산업 후보군에 배분하는 전략이 적합합니다.

추천 비중:
- 현금성 자산: 20%
- 광범위 ETF: 40%
- 성장 산업 ETF/후보군: 25%
- 개별 종목 검토 후보: 10%
- 실험 투자/대기자금: 5%

이 결과는 참고용 분석이며 실제 투자 판단은 사용자의 책임하에 이루어져야 합니다.
```

## 7.4 자산 현황 직접 입력 분석

### 기능 ID

`ASSET_001`

### 기능명

자산 현황 텍스트 분석

### 목적

사용자가 입력한 자산 현황을 AI가 구조화하고 총자산, 부채, 순자산을 계산한다.

### 주요 UI 요소

- 자산 현황 입력 textarea
- 예시 자산 현황 불러오기 버튼
- AI 분석하기 버튼
- 총자산 카드
- 부채/미결제 카드
- 순자산 카드
- 이전 대비 변화 카드
- 자산 구성 차트
- AI 자산 코멘트

### 입력 데이터

```text
토스뱅크 1,200,000원
카카오뱅크 800,000원
주식계좌 3,500,000원
청약 1,000,000원
신용카드 미결제 420,000원
```

### 출력 데이터

```json
{
  "assetItems": [
    {
      "name": "토스뱅크",
      "amount": 1200000,
      "category": "현금성 자산",
      "reason": "입출금 계좌로 추정되어 현금성 자산으로 분류했습니다."
    }
  ],
  "totalAsset": 6500000,
  "totalDebt": 420000,
  "netWorth": 6080000,
  "changeAmount": 330000,
  "changeRate": 5.74,
  "summary": "순자산이 이전 기록 대비 증가했습니다.",
  "aiComment": "현금성 자산과 투자 자산이 함께 증가해 자산 흐름은 안정적인 편입니다."
}
```

### 자산 카테고리

| 카테고리 | 설명 |
|---|---|
| 현금성 자산 | 입출금 계좌, 파킹통장 등 |
| 저축성 자산 | 예금, 적금, 청약 등 |
| 투자 자산 | 주식, ETF, 펀드, 연금저축 등 |
| 목적 자금 | 여행, 이사, 결혼, 비상금 등 |
| 부채/미결제 | 카드값, 대출, 마이너스 통장 등 |
| 기타 | 분류가 애매한 자산 |

### 계산 규칙

```text
총자산 = 현금성 자산 + 저축성 자산 + 투자 자산 + 목적 자금 + 기타 자산
총부채 = 부채/미결제 항목 합계
순자산 = 총자산 - 총부채
순자산 변화 = 현재 순자산 - 이전 순자산
변화율 = 순자산 변화 / 이전 순자산 * 100
```

### 예외 처리

| 상황 | 처리 |
|---|---|
| 입력값 없음 | 자산 현황 입력 요청 |
| 금액 추출 실패 | 항목 확인 요청 |
| 이전 자산 데이터 없음 | 비교 없이 현재 상태만 표시 |
| 부채 항목 없음 | 총부채 0원으로 처리 |

### 완료 기준

- 사용자가 입력한 자산 현황이 구조화된다.
- 총자산, 부채, 순자산이 계산된다.
- 이전 상태와 비교 결과가 표시된다.

## 11. AI Agent 설계

## 11.1 Agent 역할 정의

SKale의 AI는 단순 챗봇이 아니라 다음 역할을 수행하는 Agent이다.

| 하위 Agent | 역할 |
|---|---|
| 소비 정리 Agent | 소비 내역을 추출하고 카테고리별로 분류한다. |
| 자산 비교 Agent | 현재 자산 상태를 정리하고 이전 기록과 비교한다. |
| 자산 배분 Agent | 사용자의 자산 상태와 성향에 따라 비중을 제안한다. |
| 투자 전략 Agent | 사용자의 투자 전략을 읽고 포트폴리오 방향을 제안한다. |

---

각 항목은 반드시 아래 카테고리 중 하나로 분류한다.

- 교통

- 불확실한 항목은 기타로 분류한다.

## 11.4 포트폴리오 추천 프롬프트

```text
너는 개인 자산관리 AI Agent "SKale"이다.

사용자의 투자 성향, 투자 기간, 월 투자 가능 금액, 관심 산업, 투자 전략을 바탕으로 자산 배분 방향을 제안한다.

주의사항:
- 실제 매수/매도 지시처럼 말하지 않는다.
- "추천 종목"보다는 "검토 후보군" 또는 "자산군 비중"이라는 표현을 사용한다.
- 결과는 참고용 분석이며 실제 투자 판단은 사용자의 책임이라는 문구를 포함한다.
- 사용자가 작성한 투자 전략을 반영해 추천 이유를 설명한다.
- 응답은 반드시 JSON 형식으로만 작성한다.

투자 성향 기준:
- 안정형: 현금성 자산과 안정형 자산 비중을 높게 유지한다.
- 중립형: 코어 ETF와 성장 산업 비중을 균형 있게 배분한다.
- 공격형: 장기 성장 산업과 개별 후보군 비중을 상대적으로 높인다.
```

## 13. 비기능 요구사항

## 13.1 성능

- 주요 페이지는 2초 이내 렌더링을 목표로 한다.
- AI 분석 요청 중에는 로딩 상태를 표시한다.
- AI 응답 실패 시 mock fallback 결과를 제공할 수 있어야 한다.

## 13.2 사용성

- 시연자가 직접 입력하지 않아도 예시 데이터로 바로 체험할 수 있어야 한다.
- 모바일 화면에서도 주요 카드가 깨지지 않아야 한다.
- 금융 용어를 과도하게 어렵게 쓰지 않는다.
- AI 코멘트는 짧고 행동 중심으로 작성한다.

## 13.3 접근성

- 버튼 텍스트는 명확하게 작성한다.
- 차트만으로 정보를 전달하지 않고 금액과 비율을 함께 표시한다.
- 입력 영역에는 placeholder를 제공한다.

## 13.4 보안

- OpenAI API Key는 프론트엔드 코드에 직접 노출하지 않는다.
- Vercel 환경변수 또는 서버리스 함수를 통해 관리한다.
- 실제 민감정보 입력을 권장하지 않는다.
- 데모 데이터 사용을 기본 시나리오로 둔다.

## 19. 시연 시나리오

### 19.1 1분 시연 버전

```text
1. 대시보드에서 SKale이 소비와 자산을 한눈에 정리해주는 Agent임을 소개한다.
2. 소비 분석 화면에서 예시 소비 내역을 불러온다.
3. AI 분석을 실행해 카테고리 자동 분류 결과와 차트를 보여준다.
4. 자산 분석 화면에서 예시 자산 현황을 불러온다.
5. 총자산, 순자산, 이전 대비 변화를 보여준다.
6. 포트폴리오 화면에서 투자 성향과 전략을 입력한다.
7. AI가 추천한 자산 배분 비중과 리스크 코멘트를 보여준다.
```

### 19.2 3분 시연 버전

```text
1. 문제 상황 설명
   - 금융 정보가 여러 앱에 흩어져 있어 자산 흐름을 한눈에 파악하기 어렵다.

2. 서비스 소개
   - SKale은 소비와 자산을 AI가 구조화하고 다음 행동을 제안하는 Agent이다.

3. 소비 분석
   - 소비 내역을 입력하거나 캡처한다.
   - AI가 날짜, 사용처, 금액을 추출한다.
   - 고정비, 생활비, 여행, 투자 등으로 자동 분류한다.
   - 카테고리별 소비 차트를 확인한다.

4. 자산 분석
   - 현재 자산 현황을 입력한다.
   - 총자산, 부채, 순자산을 계산한다.
   - 이전 기록 대비 자산 변화를 비교한다.

5. 포트폴리오 추천
   - 투자 성향과 전략을 입력한다.
   - AI가 자산 배분 방향을 추천한다.
   - 투자 유의사항을 함께 제공한다.

6. 마무리
   - SKale은 단순 가계부가 아니라 돈의 흐름을 읽고 다음 행동을 제안하는 개인 자산관리 Agent이다.
```

## 20. 제출 문서용 요약

### 20.1 Agent명

```text
SKale
```

### 20.2 Agent 소개

```text
SKale은 사용자의 소비 내역과 자산 현황을 AI가 분석하여 현재 돈의 흐름을 시각화하고, 자산 배분과 투자 방향을 제안하는 개인 자산관리 Agent입니다.
```

### 20.3 제작 배경

```text
개인의 금융 정보는 카드 앱, 은행 앱, 증권 앱 등에 흩어져 있어 전체 자산 상태를 한눈에 파악하기 어렵습니다. SKale은 사용자가 소비 내역이나 자산 현황을 입력하거나 캡처하면, AI가 이를 자동으로 구조화하고 카테고리별 소비, 순자산 변화, 자산 배분 상태를 시각화합니다.
```

### 20.4 주요 기능

```text
1. 소비 내역 직접 입력 및 캡처 분석
2. 고정비, 생활비, 여행, 투자 등 카테고리 자동 분류
3. 카테고리별 지출 시각화
4. 자산 현황 입력 및 순자산 계산
5. 이전 자산 상태와 현재 상태 비교
6. 투자 성향 기반 자산 배분 추천
7. 사용자 투자 전략 기반 포트폴리오 방향 제안
```

### 20.5 기대 효과

```text
사용자는 복잡한 금융 데이터를 직접 정리하지 않아도 자신의 소비 습관과 자산 흐름을 한눈에 확인할 수 있습니다. 또한 AI가 사용자의 목표와 투자 성향을 반영해 생활비, 저축, 투자 비중을 제안하므로 개인의 재무 습관 개선과 장기 자산 형성에 도움을 받을 수 있습니다.
```
